Правила коммитов по Conventional Commits

Сообщение коммита строится по шаблону:

<тип>[область]: <краткое описание>

тип — указывает, что за изменение было сделано;
область (необязательно) — конкретная часть проекта (например, модуль или файл);
описание — кратко, что именно изменилось.

Основные типы коммитов:
Тип	 Когда использовать			 Пример
feat	 Добавлена новая функциональность	 feat: добавлен подсчёт среднего числа
fix	 Исправлена ошибка			 fix: исправлено деление на ноль
docs     Изменения в документации		 docs: добавлена инструкция по функционалу подсчета среднего числа
refactor Изменения в коде без добавления нового  refactor: упрощена логика сортировки массива
         функционала и без исправления багов
